# Ajuste visual - Lista de Português enxuta

Nesta versão, a listagem das aulas de Português foi simplificada.

Mantido em cada aula:
- Nome da aula
- Tag de prioridade
- Tempo estudado
- Questões realizadas
- Botão Estudar
- Botão Videoaula
- Botão IA

Removido da listagem de Português:
- Sem anotações / possui anotações
- Questões como botão de ação
- Materiais
- Revisões
- Resumo/Bizus
- Botões Estudei agora / Já havia estudado / Reabrir

As demais matérias não tiveram sua estrutura visual alterada por este ajuste.
