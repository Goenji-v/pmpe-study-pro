# Ajuste — Dashboard direto, históricos e busca

- O botão **Iniciar estudo** do Dashboard inicia imediatamente a sessão da missão do dia e abre a Central já preenchida.
- Sessões já em andamento não são substituídas silenciosamente; o botão abre a sessão atual.
- Cards do Dashboard agora são atalhos: Tempo → Histórico de sessões; Questões → Histórico de questões; Acertos → Estatísticas; Sequência → Histórico da semana.
- Busca do Dashboard abre Conteúdos com o campo de pesquisa focado.
- Rotas legadas `/buscar`, `/pesquisa` e `/search` agora apontam para Conteúdos para evitar 404.
