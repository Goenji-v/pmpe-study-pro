# Dashboard 2.2 — Etapa 2

Incluído:
- Meta diária consolidada (tempo, questões e revisões)
- IA Coach contextual na Dashboard, com ação direta
- Estatísticas Hoje / Semana / Mês / Total
- Conquistas visuais desbloqueadas por dados reais
- Correção da duplicação de tempo em novos registros automáticos da Central de Estudos
- Compatibilidade histórica na Dashboard: registro de questões correspondente a uma sessão não duplica minutos

Validação local recomendada:
1. npm install
2. npm run build
3. npm run dev

Observação: o build no ambiente de geração não pôde rodar porque as definições locais de vite/client e node não estão instaladas nesse ZIP. Rode npm install antes do build no VS Code.
